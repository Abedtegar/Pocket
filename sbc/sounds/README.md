# sounds/

`python tools/make_sounds.py` membuat WAV placeholder (beep):
`panic.wav`, `weapon.wav`, `hr.wav`, `zone.wav`, `offline.wav`, `battery.wav`, `test.wav`.

Ganti dengan rekaman suara arahan dengan nama file yang sama (isi suara masih keputusan terbuka K7).
Format yang aman untuk `aplay`: WAV PCM 16-bit, mono, 22050/44100 Hz.
